# Вечерний практический блок (18:30 МСК)

> Второй пост дня. Утро 10:00 — история обычного человека, вечер 18:30 — короткая
> практика. Публикует тот же бот, что и истории. Файлы: `artifacts/api-server/evening/<weekday>/`.

## Ротация по дням недели

| День | Формат | Папка |
|---|---|---|
| Пн | 📩 Разбор реального сообщения (текст мошеннического SMS + что палит) | `mon/` |
| Вт | 🚩 Схема: 3 красных флага | `tue/` |
| Ср | 🧪 Опрос «проверь себя» (native Telegram quiz) | `wed/` — `.json` |
| Чт | 📖 Слово дня (вишинг, смишинг, SIM-swap…) | `thu/` |
| Пт | ✅ Чек-лист на 2 минуты | `fri/` |
| Сб | 👨‍👩‍👧 Родительский уголок | `sat/` |
| Вс | 🌍 Мир за неделю (3 истории/вывода, не новостной дайджест) | `sun/` |

Внутри папки может быть несколько файлов — они чередуются по неделям
(индекс недели % количество файлов). Добавили второй файл — на следующей
неделе выйдет он, через неделю снова первый.

## Форматы файлов

- `.txt` — обычный пост, 100–160 слов, простой язык, 2–4 пункта, CTA, 2–3 хэштега.
- `.json` — опрос: `{"question": "...", "options": ["..."], "correct": 1}`.
  `correct` — индекс правильного варианта (0-based), опрос отправляется как quiz.

## Защита от повторов

Ключ публикации — хэш `evening:<день>:<файл>:<дата>` хранится в `channel_posts`
(`post_type='evening'`). Повторный запуск в тот же день ничего не отправит.

## Правила контента

- Только практика, без пересказа новостей и без «страшилок ради страшилок».
- Один пост = одно действие или одна мысль.
- Не дублировать утреннюю историю: вечер дополняет её, а не повторяет.
- Проверяемые факты (номера, адреса, названия) — только реальные.
