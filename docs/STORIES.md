## Правила отбора

- Только реальные, документированные случаи (новости, полиция, суды).
- Герой — обычный человек (не компания и не знаменитость): возраст, город, профессия.
- Пересказ простым языком: что случилось → как поверил → чем закончилось.
- Не стыдить жертву, не пугать, без канцелярита; финал — 2–3 практических вывода.
- География — весь мир, не только Россия.
- Источник фиксируется в этом файле, в самом посте — не нужен.

## Как добавить историю

1. Найти документированный случай (не «в интернете писали», а публикация СМИ/полиции).
2. Проверить: имя/возраст/город/сумма/дата — по источнику.
3. Записать файл `NNN-slug.txt` по шаблону ниже.
4. Добавить строку в индекс с источником.
5. Задеплоить (stories копируются в образ при сборке LinkGuard).
