# Истории канала — формат

Один файл `.txt` = один пост. Файлы публикуются по порядку имён (001, 002, …),
по одному в день в 10:00 МСК. Опубликованное запоминается в БД (`channel_posts`,
`post_type = 'story'`), повторно не уходит.

Шаблон:

```
😱 <крючок: одной фразой, что случилось>

<город, страна, дата. Кто герой: возраст, обычная жизнь>

<как началось: звонок, сообщение, ссылка>

<что произошло: чем давили, что человек сделал>

<чем закончилось>

Что важно понять:
• <вывод 1>
• <вывод 2>
• <вывод 3>

<CTA: кому показать/переслать>

#история #мошенники #<тема>
```

Требования: 180–260 слов, простые короткие предложения, никакой разметки
(только текст, допускаются эмодзи-маркеры), не стыдить жертву, не пугать.
